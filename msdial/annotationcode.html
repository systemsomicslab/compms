Compound identification and annotation confidence
Annotation code: Version 1.0
MS-DIAL versions
This page describes the code written by MS-DIAL 5.5.261105 and later. The code is written to the "Annotation tag (VS1.0)" column of the text exports and to the reliability column of mzTab-M (MS:1003032).
450 is new in MS-DIAL 5.5.261105: MS/MS matched to a spectrum from a library declared as predicted (in silico). It is never combined with RT or CCS and is not used in lipidomics projects.
Since MS-DIAL 5.5.261018, a reference without a retention time or retention index never gives an RT/RI match, and the RT/RI match uses the tolerance set by the user up to 2 min for RT, 150 for Kovats RI and 50,000 for Fiehn RI. Earlier MS-DIAL 5 releases could give an RT match (3x0, 520 or 340) for a reference without a retention time. 5.5.261018 was a console pre-release; the first full release with this change is 5.5.261105.
MS-DIAL 4 used 0.5 min for LC-MS, and 0.1 min, Kovats RI 20 and Fiehn RI 2000 for GC-MS.
In LC-MS/MS projects without ion mobility, an MSP-based search gives the RT match only when "Use retention time for scoring" is on.
520 and 530 (and 500 and 510) cover three cases: no MS/MS spectrum, an MS/MS comparison below the threshold, and an MS/MS comparison that explained nothing. The Evidence source column (PrecursorOnly, WeakSpectrumMatch, UnmatchedSpectrum) tells them apart.
999 is also written for a structure accepted from MS-FINDER in the graphical interface.
